02 · GitHub ayarları

Sadece nuevols reposu için Contents: Read and write izni ver. Anahtar yalnızca GitHub API’ye gönderilir; tarayıcı ayarlarına veya indirilen dosyalara kaydedilmez.
GitHub anahtarı nasıl oluşturulur?

GitHub anahtar oluşturma sayfasını aç. Token name: Nuevols Publisher. Resource owner: hesgeneric. Repository access: Only select repositories → nuevols. Repository permissions: Contents → Read and write. Generate token düğmesine basıp çıkan anahtarı yukarıdaki alana yapıştır.

Sohbetteki GitHub bağlantısı bu bağımsız HTML dosyasına otomatik yetki sağlamaz.

03 · Yüklenecek kod şablonu

{{URL}}: adresi olduğu gibi yerleştirir. {{URL_JSON}}: adresi tırnakları ve kaçışlarıyla geçerli bir JavaScript/JSON string değeri olarak yerleştirir; etrafına tekrar tırnak koyma.
Kod şablonu ve ayarlar bu tarayıcıda saklanır. Girilen kod uygulama içinde çalıştırılmaz. JSON seçildiğinde oluşan dosyanın JSON biçimi kontrol edilir.

04 · Çıktı URL şablonu

{{FILE_URL}}: jsDelivr adresi · {{FILE_URL_ENCODED}}: URL parametresi için kodlanmış adres · {{FILENAME}}: dosya adı · {{PATH}}: repo içindeki yol
Sadece jsDelivr bağlantıları için {{FILE_URL}} bırak. Şablon değişiklikleri sonuçlara anında uygulanır; sonuç kutusunu ayrıca elle düzenleyebilirsin.
